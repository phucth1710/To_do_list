# To-Do List

A server-rendered to-do application built with Express, MongoDB, and EJS. Items persist in MongoDB, and any URL path becomes its own named list on the fly.

## Features

- **Daily list** — the home route opens a list titled with the current date, generated by `date.js`.
- **Dynamic named lists** — visiting `/groceries` or `/work` creates and loads that list on first request via the `/:customListName` route; no setup needed.
- **Add and delete items** — form posts add entries, and checking an item removes it from its list.
- **Persistent storage** — all items and lists are stored in MongoDB through Mongoose schemas, so state survives a restart.

## Tech stack

| Layer | Technology |
|---|---|
| Server | Node.js, Express 4 |
| Templating | EJS |
| Database | MongoDB with Mongoose 5 |
| Utilities | body-parser, lodash |

## How it works

Two Mongoose models back the app:

- `Item` — a single to-do entry.
- `List` — a named list holding an array of `Item` documents.

The `/:customListName` route uses `lodash.capitalize` to normalize the path into a list name, looks it up, and creates it seeded with default items if it doesn't exist yet. That single route is what makes arbitrary named lists work without any explicit "create list" step.

## Running locally

Requires Node.js and a local MongoDB instance.

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start MongoDB. On Windows, run `mongod.exe` from your MongoDB `bin` directory — for example `C:\Program Files\MongoDB\Server\4.4\bin` (substitute your version). On macOS or Linux, `mongod` or `brew services start mongodb-community`.
3. Start the server:
   ```bash
   node app.js
   ```
4. Open <http://localhost:3000/> for today's list, or any path such as <http://localhost:3000/groceries> for a named one.

The app connects to `mongodb://localhost:27017/todolistDB` by default.
